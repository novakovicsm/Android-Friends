# Maps

## forest.tmx
Első pálya placeholder (erdő). A map a `forest.tsx` tilesetet használja.

Teendő:
- Hozz létre egy 128x128 px tileset képet `forest_tiles.png` néven ebbe a mappába.
- A tileset 4x4 rács (16 tile), tile méret 32x32 px.
- Export után Tiled-ben frissítsd a tilesetet, és ellenőrizd a mapet.
